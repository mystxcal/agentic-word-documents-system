# Vendored typefaces

The banner is typeset with three open families. Each file here is a subset of
the upstream release: Latin glyphs plus the punctuation the artwork uses, in
WOFF2. Source Serif 4 additionally has its optical-size axis pinned, so the
display cut and the text cut are genuinely different drawings rather than one
outline scaled.

| File | Family | Upstream | Licence |
|---|---|---|---|
| `SourceSerif4-Display.woff2` | Source Serif 4 (`opsz` 60, `wght` variable) | [adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif) | SIL OFL 1.1 |
| `SourceSerif4-Text.woff2` | Source Serif 4 (`opsz` 11, `wght` variable) | same | SIL OFL 1.1 |
| `SourceSerif4-Italic-Text.woff2` | Source Serif 4 Italic (`opsz` 16) | same | SIL OFL 1.1 |
| `Inter-var.woff2` | Inter (`wght` variable) | [rsms/inter](https://github.com/rsms/inter) | SIL OFL 1.1 |
| `JetBrainsMono-var.woff2` | JetBrains Mono (`wght` variable) | [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono) | SIL OFL 1.1 |
