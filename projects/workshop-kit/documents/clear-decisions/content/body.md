# Use this pattern when {#use-this-pattern-when}

A group has discussed the same question more than once, several answers sound reasonable, and nobody can state what would make one option better than another.

This pattern does not manufacture agreement. It gives the disagreement a visible shape, makes the decision rule explicit, and ends with a named owner and next checkpoint.

:::important
Do not invite a group to decide something that has already been decided elsewhere. If the room can only advise, say so before the first activity.
:::

# The ninety-minute arc {#the-ninety-minute-arc}

:::insert session-map

The arc has three movements. **Reveal** puts the evidence and tensions on the wall. **Shape** turns preferences into comparable choices. **Commit** records the decision in language another person could repeat tomorrow.

# Before people arrive {#before-people-arrive}

Prepare one decision sentence with a blank:

```text
By the end of this session, we will decide ______ so that ______.
```

Then prepare the room:

- one wall or board that everyone can see;
- one card per option;
- a visible timer;
- a parking area for important questions that do not change today's decision.

# Facilitation moves {#facilitation-moves}

## Reveal: make the disagreement legible

Ask each person to write one fact, one concern, and one condition for a good outcome. Cluster duplicates before discussion. The facilitator names the clusters without interpreting them.

## Shape: compare choices using the same lens

Write the decision criteria before scoring any option. If a criterion appears only after a preferred option performs badly, pause and test whether the criterion is real or tactical.

## Commit: say what changed

The final record needs four elements:

1. the choice;
2. the reason it won;
3. the owner of the next action;
4. the date or event that triggers a review.

# Close the room well {#close-the-room-well}

Read the decision aloud. Ask one person who did not lead the discussion to repeat it in their own words. If their version changes the meaning, the record is not clear enough yet.

End by naming what remains unresolved. A good close does not pretend every concern disappeared; it separates the decision from the work that follows.
